# 🧠 Face Detection using OpenCV & Python

This project demonstrates real-time **face detection** using a webcam and the **OpenCV** library in Python. It uses Haar Cascade classifiers to detect human faces from live video feed captured through the system's camera.

## 🚀 Features

- Real-time face detection using webcam  
- Simple and efficient implementation with OpenCV  
- Highlights detected faces with bounding boxes  
- Easily extendable for face recognition/matching


## 🔧 Requirements

- Python 3.x  
- OpenCV  
- Webcam (inbuilt or external)

Install OpenCV with:

```bash
pip install opencv-python
```
▶️ How to Run
```
python Live_face_detection.py
```
